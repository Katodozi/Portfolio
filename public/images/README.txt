Profile photo instructions
==========================

Drop your photo as ONE of these files in this folder:

  profile.webp   (recommended — smallest file size)
  profile.jpg
  profile.png

The site loads /images/profile.webp first. If that file is missing,
/images/profile-placeholder.svg is shown automatically (no 404).

Optimal dimensions: 800×1000px (4:5 portrait ratio).

Open Graph image
================

Replace /public/og-image.jpg with a 1200×630px image for social sharing.
A starter SVG source lives at /public/og-image.svg — export it as JPG
from Canva or Figma if you want a custom design.
